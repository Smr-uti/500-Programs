# 📝 About
In this repository, I am practising Python from basic to advanced levels. It includes a wide variety of problems ranging from simple syntax exercises to complex logic implementation.
# 💡 Key Topics Covered:
⬤ **Python Basics:** Variables, Data Types, Type Casting, and User Input.

⬤ **Operators:** Arithmetic, Logical, Comparison, Bitwise, and Assignment operators.

⬤ **Control Flow**: If-else statements, Nested if-else, and Match-case.

⬤ **Loops:** For loops, While loops, Nested loops, Break, Continue, and Pass statements.

⬤ **Strings:** Slicing, Methods, Formatting, and String manipulation.

⬤ **Lists and Tuples:** Indexing, Slicing, Methods, List Comprehension, and Unpacking.

⬤ **Dictionaries and Sets:** Key-Value pairs, Set operations, and Membership testing.

⬤ **Functions:** Defining functions, Arguments, Keyword arguments, Lambda functions, and Scope.

⬤ **Modules and Packages:** Importing modules, Math module, Random module, and OS module.

⬤ **Exception Handling:** Try, Except, Else, Finally, and Custom Exceptions.

⬤ **Object-Oriented Programming:** Classes, Objects, Inheritance, Encapsulation, Polymorphism, and Abstraction.

⬤ **Advanced Topics:** Generators, Decorators, Iterators, and List Comprehensions.
